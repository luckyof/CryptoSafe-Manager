# Sprint 8 User Feedback Report

Этот документ фиксирует проверку приложения с 5 пользователями перед защитой Sprint 8.
Его цель - показать, какие замечания были получены, какие решения приняты и где именно проект был исправлен.

## Как собирать фидбек

Каждому пользователю нужно дать один и тот же короткий сценарий:

1. Запустить приложение из исходного кода или собранного `dist/CryptoSafeManager/CryptoSafeManager.exe`.
2. Создать или открыть хранилище.
3. Добавить тестовую запись с логином, паролем, URL и заметкой.
4. Найти запись через поиск или фильтр.
5. Скопировать пароль в буфер обмена и дождаться автоочистки.
6. Открыть настройки и проверить понятность параметров безопасности.
7. Проверить импорт/экспорт на тестовых данных.
8. Сообщить, что было непонятно, неудобно или выглядело как ошибка.

Важно: пользователи не должны вводить реальные пароли, банковские данные или рабочие секреты.

## Итоговое резюме

После проверки с 5 пользователями нужно кратко описать:

- какие проблемы повторялись чаще всего;
- какие замечания были исправлены в рамках Sprint 8;
- какие замечания перенесены в будущую работу;
- какие тесты или ручные проверки подтверждают исправления.

Пример итоговой формулировки:

```text
В проверке участвовали 5 пользователей с разным уровнем опыта. Основные замечания касались понятности настроек, заметности статуса буфера обмена и документации по запуску. По результатам проверки были уточнены тексты интерфейса/документации, обновлены инструкции запуска и добавлены пояснения по безопасному использованию. Исправления проверены повторным ручным сценарием и полным запуском pytest.
```
